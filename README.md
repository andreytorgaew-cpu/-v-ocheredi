# В ОЧЕРЕДИ

Веб-прототип аркады про очередь за бензином.

## Запуск через GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. Через несколько минут игра будет доступна по адресу GitHub Pages.

Главный файл игры — `index.html`.
